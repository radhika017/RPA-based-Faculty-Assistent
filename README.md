# 📌 Overview

During the COVID-19 pandemic 📚, schools and colleges shifted to online learning platforms like Google Classroom. Teachers faced challenges managing assignments, tracking student progress, and handling administrative work.

To reduce manual effort and improve productivity, this project introduces an **RPA-based Faculty Assistant** developed using **UiPath** 🤖.

The bot automates repetitive academic and administrative tasks, helping teachers focus more on teaching and student engagement.

# 🚀 Getting Started

## 1️⃣ Install UiPath Studio

Download UiPath Studio from:

[UiPath Official Website](https://www.uipath.com/?utm_source=chatgpt.com)

---

## 2️⃣ Clone Repository

```bash id="w6t2fj"
git clone https://github.com/radhika017/RPA-based-Faculty-Assistent-main.git
```

---

## 3️⃣ Open Project

* Launch UiPath Studio
* Open the downloaded project folder
* Load `Main.xaml`

---

## 4️⃣ Run Automation

Click ▶️ **Run** inside UiPath Studio to execute the workflow.

---

# 💡 How It Works

1. Faculty uploads or manages academic tasks
2. UiPath bot reads and processes data
3. Repetitive tasks are automated
4. Reports and updates are generated automatically
5. Teachers save time and effort
